# wanmap-data

犬の集まり予測マップ「WanMap」の施設データ配信リポジトリです。

- `facilities.json` … 日本全国のドッグラン・ドッグカフェ等の施設情報（公式サイト・公式SNS等で確認できた公開情報のみ）。アプリが起動時に新版をチェックし、自動で差し替えます。
- 個人情報は含まれていません。ユーザーがアプリ内で追加・編集した場所の情報も含まれません（端末内にのみ保存されます）。
- データ形式：`{ dataset, version, generatedAt, count, facilities[] }`。施設の追加・修正はこのリポジトリの更新だけで反映でき、アプリの再審査は不要です。

情報の正確性について：営業時間・料金等は変更される場合があります。必ず施設の公式情報をご確認ください。
